# ZeroMimic 技术设计

## 1. 目标与范围

当前代码已提供任务判定、仿真与回放合同、混合搜索、策略学习组件及单轮编排。真机模型场景、Warp 复验适配器和可训练的共享动力学仍是后续集成目标。可用 `PYTHONPATH=src python -m supermimic.scripts.train_zero --describe` 查看当前任务配置。

在 SuperMimic 的 PyTorch、mjlab 和 MuJoCo Warp 底座上，为 Unitree G1 增加一条无动捕训练链路。受限空间起身、变净高通道和可调箱式越障从首次联合运行起共用一套任务条件化的世界模型集成、策略和价值网络。训练时用动作块搜索发现动作，由物理仿真复验并蒸馏。演示时加载一个策略检查点，根据当前观测执行，关闭搜索。

箱式越障是主展示。以相同起点、终点和检查点改变箱高和顶面深度，观察策略是否自主选择跨步、手撑或上箱后下落。主展示记录动作和接触事实，实际结果决定可以展示的地形范围。

## 2. 三项任务

`H` 为当前 G1 资产在标称站姿下的碰撞体总高，`h_stand` 为该姿态的骨盆离地高度。几何以米配置，难度预设可用 `H` 表达。判定使用实际碰撞体边界、接触和任务计时器。

| 任务 ID | 场景与初始化 | 训练信号 | 物理成功条件 |
| --- | --- | --- | --- |
| `get-up` | 侧墙在左侧或右侧，位置和可用空间可变。仰卧、俯卧、侧卧起点由关节限位内的随机姿态自然落稳得到。剔除穿模和已经站立的起点。 | 骨盆抬升和躯干直立。允许借地或借墙，成功条件约束最终支撑。 | 骨盆高度至少为 `0.9 × h_stand`，躯干倾角不超过 20°，根部线速低于 0.25 m/s、角速低于 0.7 rad/s。脚与地面接触，手、躯干和侧墙均无承重接触，连续满足 0.5 秒。记录起身耗时和 1 秒内成功率。 |
| `tunnel` | 用固定数量的顶棚段组成起伏净高，净高测量自地面至顶棚下表面。配置段长、净高和宽度，侧壁封闭绕行路线。起点在入口外，出口为固定平面。 | 沿通道向出口推进，惩罚头胸撞顶与机械功。策略观察前方各段几何。 | 从指定入口进入，所有机器人碰撞体越过出口平面，整个穿行过程无超过接触阈值的头胸撞顶。记录穿行时间、最小净高和碰撞。 |
| `box` | 实心箱体高度和顶面深度可调，起点位于箱前，终点位于箱后。使用侧边界约束路线，配置接近位置和角度。 | 沿起点至落区方向推进。允许脚踩、掌撑和前臂借力，由资产碰撞体实际决定可用接触。 | 全身越过箱体远端面，在箱后地面落区用脚支撑，根部低速且稳定保持 0.5 秒。记录箱高、深度、完成时间与手脚接触序列。 |

三项任务均采用**一次性终点奖励、平滑进展、动作变化惩罚**。任务进展使用有界势函数 `gamma * Φ(next) - Φ(current)`，任务终止时把后继势设为零。箱式越障和通道用路线坐标，起身用高度和直立度。受限力矩下的正机械功按 `sum(max(tau * joint_vel, 0)) * dt` 计算，启用时从仿真读取实际执行器力矩。任务配置记录接触阈值和单位。三任务使用同一奖励尺度，给终点奖励一个共同的基准值，再按进展、碰撞或功耗的物理量纲配置代价系数。策略自主选择肢体及接触顺序。

三个任务在每轮均有采样配额。任务内按几何或起始姿态分桶，保留配置的目标难度份额。箱高从可迈过的档位覆盖到允许手臂借力的档位，具体取值由当前 G1 关节限位、碰撞体和执行器配置核定。训练、调参和演示的场景种子及几何组合分开保存。

### 3.1 场景、状态和动作约定

| 对象 | 约定 |
| --- | --- |
| `SceneSpec` | `task_id`、`scene_id`、几何参数、场景坐标到世界坐标变换、物理参数、重置种子及初态。几何使用固定拓扑，每个仿真批次共享同一已编译几何配置。几何变化通过配置桶调度。 |
| `TaskState` | `step_index`、通行标记、禁止接触标记、连续站稳步数等。成功、失败和截止时间由任务规则根据实际转移更新。任务时限在观测中以剩余时间表达。 |
| `RobotState` | 与现有 GenCoord 一致的根部位置、四元数、根部速度和关节位置、速度。根部完整位姿保留在 `aux_state`，用于每步重算相对几何。 |
| `Action` | 使用现有 `[B, A]` 策略动作坐标，`A` 从 G1 动作管理器读取。对幅值和变化率统一投影，再用既有 scale/offset 映射为关节位置目标。缓存投影后、scale/offset 前的动作，复验和动力学都读同一份。 |
| `ActorObs` | 四帧本体观测、上一控制动作、任务 ID、定长相对几何及有效位掩码、剩余时间。几何从当前姿态变换到机器人坐标，保持倒地姿态下的坐标一致性。策略和搜索共用这一输入定义，回合起步用首帧填满历史。 |

`PhysicsTaskSpec` 提供 `sample_scene()`、`observe()`、`evaluate(before, after, action)` 和 `score_model_step()`。`evaluate()` 使用仿真的接触和碰撞体边界生成真实奖励及硬判定。`score_model_step()` 使用同一任务定义中的连续量，并以可微近似计算接触、计时与成功。两条路径使用同一进展坐标、动作尺度、折扣和奖励系数。

### 3.2 仿真分支与数据合同

`ZeroSim.step()` 返回下一次自动重置前的观测、`next_state`、奖励、接触摘要、`terminated`、`truncated` 和 `success`。任务成功、不可恢复的违规或任务自身的截止时间属于 `terminated`。外部采集截断属于 `truncated`，保留真实后继状态供价值引导。

物理复验池与策略采集池独立。初始实现通过同一 `SceneSpec`、确定性重置和已执行动作前缀重建起点，使用相同仿真后端、控制步和扰动序列，以重建执行器、求解器热启动、任务计数和观测历史。分支前检查根部及关节状态、上一动作、计时器和任务标记是否在容差内，并从记录恢复策略模式状态。复现失败则丢弃该起点并记录误差。完整快照快路径须遵守同一一致性合同，并覆盖物理积分状态及环境管理器状态。 [MuJoCo 仿真状态](https://mujoco.readthedocs.io/en/stable/programming/simulation.html)

| 采样视图 | 数据合同 |
| --- | --- |
| 动力学 | `episode_id`、`scene_id`、`step_index`、`source`、当前与下一物理状态、动作、上一动作、接触、奖励和终止标记。纳入策略采集和真实复验中的成功、失败转移。八步监督使用九帧状态，序列完整位于同一 episode。 |
| Critic | 冻结版本的当前策略采集段，包含 actor/critic 观测、模式及段内剩余步数、真实奖励、后继观测和终止标记。起步探索和搜索强制执行段仅供动力学视图使用。 |
| 蒸馏 | 每个搜索起点最多一条赢家前缀。保存实际执行到的观测、投影后动作、模式、权重和有效掩码，使用 `snapshot_id` 关联复验记录。 |

现有 `ReplayBuffer.insert()` 要求固定环境批大小。采集池与复验池分别写入固定批次或独立轨迹块，再统一采样。终止转移始终保留重置前的 `next_state`，后续场景生成新 `episode_id`。运行中的回合保留动作前缀供随时复验，终止回合的前缀在对应复验结束后释放。前缀重放步数计入仿真开销，只将分支后的新转移写入动力学回放。 [现有 ReplayBuffer](../src/supermimic/replay_buffer.py)

## 4. 训练闭环

同一轮次内，采集和复验使用冻结的当前策略。拟合世界模型和真实轨迹 critic 后冻结其权重，再执行搜索、复验、入库及策略更新。世界模型或 critic 参数冻结时保留它们对输入状态与动作的导数。

1. **采集。** 三任务并行运行。起步时额外分配一部分环境执行限幅低频扰动，以覆盖跌倒和接触边缘。所有任务入口及学习模块从首轮接通。每项任务有足够的合法序列后纳入该轮的对应更新，空蒸馏批次通过掩码跳过。
2. **拟合世界模型和 critic。** 四个独立初始化的 GenCoord 成员按 episode 重采样。每个成员展开自己的 `aux_state` 和 `rep_state`，以任务 ID、物理参数和每步按预测位姿计算的相对几何为条件。本体状态做自回归监督，对接触、不可恢复失败及选用的正机械功增加观测头。起身与落地的稳定条件使用软计时器，真实成功奖励取自物理转移。归一化统计按轮冻结。Critic 用当前策略自然采集的轨迹做真实 TD(λ)。任务终止时零引导，外部截断用重置前的后继观测引导，并在此处截断 λ 递推。
3. **混合搜索。** 从有效仿真起点启动，策略按模式提供 CEM 种子。每个候选在所有集成成员上执行同一条动作序列，各成员对奖励和末端价值按预测存活概率加权。使用 `mean(J_e) - beta * std(J_e)` 排序，回报分歧和奖励使用同一尺度。CEM 对低频动作节点做无梯度批量评分，各模式独立更新采样分布，再合并精英并展开成全频控制序列。精修时固定模型和 critic 参数，对动作残差做 Adam 更新，每步投影到动作幅值与变化率约束内。箱式越障的精修窗口由粗搜预测到的关键接触定位，没出现接触时用最接近箱体的位置确定窗口，整段前向展开仍为评分的一部分。保留部分精修前候选供复验。
4. **物理复验。** 同一起点的候选在相同物理条件下执行，序列结束后由冻结策略接管，直到任务结束。记录完整的真实折扣回报 `G_phys`。硬规则合格的候选按真实回报取赢家，优势 `A = G_phys - V(snapshot)` 为正才写蒸馏数据。由于外部限制提前中断的复验可供动力学训练，蒸馏只使用具有完整回合回报的候选。所有有效仿真转移进入动力学视图。
5. **策略更新。** Actor 损失为悲观回报下的闭环 BPTT 加优势加权蒸馏。蒸馏在模式选择步用交叉熵监督选头，在前缀内做执行动作的 Huber 回归。优势权重按 `exp(clamp(A / temperature, 0, max_log_weight))` 计算并在各任务批内归一化，前缀等权分配起点权重。新策略在下一轮采集和复验接管时生效。

Actor 使用共享主干与四个可学习动作头。模式由策略在每八个控制步的段边界选择并锁定到段末。搜索起点与段边界对齐，搜索为各模式保留候选配额，精修候选继承种子的模式 ID。蒸馏用首段实际执行的动作和观测，并与该分支实测回报关联。训练时模式采样使用显式随机种子，BPTT 将离散选择视为固定索引，选择器通过蒸馏更新。仿真回放使用最大概率模式和闭环动作。

### 启动配置

| 项目 | 初始值 |
| --- | --- |
| 世界模型 | 4 个成员，8 个自回归监督步 |
| Actor BPTT | 32 个控制步，`gamma=0.995`，`lambda=0.95` |
| 规划时长 | 起身和通道约 1.3 秒，箱式越障约 2.6 秒。按 `env.step_dt` 转为最接近的八步倍数。 |
| 搜索量 | 每 4 个控制步一个节点，每起点 256 条候选、3 轮 CEM，8 条精英各做 5 次精修。箱式精修窗口起配 24 步。 |
| 复验量 | 每个起点 4 条候选，初始每轮每任务抽 1 个起点。按设备内存和实际复验耗时配置并发。 |
| 任务截止时间 | 起身 5 秒，通道与箱式越障 12 秒。站稳保持时间按控制步向上取整。 |

这些值用于启动联合训练。计时、奖励系数、搜索预算、场景配额及尺度全部写入运行配置。任务池按任务和几何桶调度，CEM 前向可分块。只在固定张量形状且地址稳定的搜索与学习计算上使用 CUDA Graph，环境重置、前缀重放和回放采样保留在外。 [现有 CUDA Graph 封装](../src/supermimic/learners/learner_utils.py)

## 5. 运行、验收与排查

计划提供以下命令。默认开启三项训练任务，回放使用同一策略检查点。

```bash
uv run src/supermimic/scripts/train_zero.py --device cuda:0 --seed 0
uv run src/supermimic/scripts/play_zero.py --checkpoint logs/zeromimic/checkpoint.pt --task box --scene-seed 1001
```

在训练轮次边界保存 actor、critic、集成模型、优化器、归一化、随机数状态、难度采样状态和回放引用。恢复时从新的物理回合开始，并保留已经完成轮次的学习状态。演示入口支持指定任务和场景，记录成功、失败理由、接触事件和控制时间。

实现后的联合验收以同一个训练进程为单位。三项任务都应产生合法仿真轨迹、模型更新、搜索和复验日志，合格教师数据可进入策略更新。CPU 合同测试覆盖成功边界、禁止接触、绕行与箱顶停留、动作投影、终止与截断、序列掩码及精修的输入梯度。GPU 联调覆盖相同起点复现、重置前后继状态、集成更新、空教师批次和检查点恢复。技能结果以关闭搜索的策略在留出场景上报告，箱式越障按高度和深度记录成功与接触方式。

| 联调现象 | 使用日志定位 |
| --- | --- |
| 分支第一步就偏离同一起点 | 按 `snapshot_id` 核对初态、动作前缀、物理参数、观测历史与计时器。 |
| 想象里过障，复验时卡在接触 | 检查每种接触类型的状态误差、几何重算、预测与实测回报差及动作修正幅度。优先回灌对应失败片段。 |
| 候选缺乏有效接近或起势 | 查看时域覆盖的秒数、动作饱和、候选模式分布和目标难度桶的转移数量。 |
| 教师成功，关闭搜索后策略失败 | 检查赢家的模式和执行前缀是否对齐，按状态追踪学生失稳后是否获得新的搜索标签。 |
| 联合训练吞吐下降 | 区分世界模型前向、精修反传、复验前缀重放和候选执行时间。仿真步数单独计入前缀重放成本。 |
